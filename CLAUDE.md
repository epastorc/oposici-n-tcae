# Instrucciones del proyecto

- Cada cambio que se suba a GitHub debe publicarse en GitHub Pages.
- La rama de despliegue es `develop`; el workflow `.github/workflows/pages.yml` se ejecuta con cada `push` a esa rama.
- Tras empujar cambios, espera a que termine el workflow `Deploy GitHub Pages` y verifica la publicación consultando `https://epastorc.github.io/oposici-n-tcae/version.json`.
